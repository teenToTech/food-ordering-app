# 🍔 Food Ordering App (Flask)

A simple full-stack web application built using Flask where users can place food orders and view them instantly on the same page.

---

## 🚀 Features

- Take user name input
- Select food item from dropdown
- Store orders in backend (Python list)
- Display all orders dynamically on webpage

---

## 🛠️ Tech Stack

- Python (Flask)
- HTML
- CSS
